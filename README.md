# ASM3 email assets

Images used by the HTML email of the UiPath robot ASM3_Quan_Nguyen (COVID-19 Stat-Alert, RPA internship assignment). Everything is drawn by code.

- header.gif: 'COVID-19 STAT-ALERT' title (Baruzen Karma / Qetod fonts, personal use), 3D coronavirus, sorcerer characters (fan art drawn by code).
- countries/<slug>.gif: country name (Kingdom Hearts font, personal use) over its waving flag (flags from worldometers.info).
- body.gif, pattern.jpg: animated space background and the repeating outer background.
- jjk/: talismans, turning wheels, percentage seals, panels, report frame, titles, and character images (Qetod, Crown Title, Kingdom Hearts, Death Note and Cloister Black fonts, personal use).

Font files are not included.
