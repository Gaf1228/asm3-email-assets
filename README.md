# ASM3 email assets

Images used by the HTML email of the UiPath robot ASM3_Quan_Nguyen (COVID-19 Stat-Alert, RPA internship assignment).

- header.gif: animated 'COVID-19 STAT-ALERT' title (rendered with the Baruzen Karma font, personal / non-commercial use) with a 3D coronavirus drawn by code.
- countries/<slug>.gif: country name (rendered with the Bleach font, personal use) over its waving flag (flags from worldometers.info).
- body.gif: animated space background of the lower part, drawn by code.
- jjk/*.png: section titles (rendered with the Qetod font, personal use), jjk/talisman_*.jpg: statistic cards drawn by code, and jjk/digits/<key>/*.png: number characters (rendered with the Manga Temple font by Blambot, personal use).
- countries/<slug>.gif: country names rendered with the Kingdom Hearts font (personal use).

Font files are not included.
